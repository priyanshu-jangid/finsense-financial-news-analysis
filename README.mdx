
# Agentic Supply Chain Guardian

Software Engineering Lab Project (BCSE301L)

## Team

* Priyanshu Jangid

## Project Overview

Agentic Supply Chain Guardian is an AI-powered supply chain monitoring and automation platform that detects risks, monitors logistics events, and assists decision-making using intelligent software agents.

## Project Structure

* `api/` — Backend API source code.
* `docs/` — Software Engineering documents.
* `tests/` — Unit and integration tests.
* `scripts/` — Utility scripts.
* `requirements.txt` — Python dependencies.

## Tech Stack

* Python
* FastAPI (planned)
* PostgreSQL (planned)
* Docker (planned)
